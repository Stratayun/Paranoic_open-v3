Поручение владельца: ревью форматов 1.8/1.9 и проверка блока 4.
Исходная ревизия — `441b7c0`; исправления форматов — `206fa25`;

## Границы результата и остаточные риски

- **Блок 4 целиком не закрыт.** Нет полного сквозного прогона всех экранов,
  системного picker/реальных SAF-провайдеров, TalkBack/клавиатуры/крупного шрифта,
  Windows DPAPI/MSI/media runtime и реального ARM64/16-КиБ устройства.
- Новые Android instrumented-тесты **не выполнялись**. KVM в среде недоступен
  (`KVM requires a CPU that supports vmx or svm`); программный API 35 дошёл
  до ADB, но не до завершения загрузки/запуска тестов, попытка остановлена.
  Прежние 13 тестов workflow 43331691152 не подтверждают новый код.
- Windows cross-check остановился на отсутствии x86_64-w64-mingw32-gcc;
  страницу ручного workflow открыть не удалось. Нынешний код не объявляется
  проверенным на Windows по прежнему успешному CI.
- Android PDF/7z worker остаётся с UID приложения: отдельный executable не
  заменяет isolatedProcess. Pdfium не поставлен в этом APK; инспектор profile
  core и сборка worker не доказывают PDF runtime/sandbox. У-4 остаётся.
- Desktop entry point не подключает AppSession.pause к потере фокуса или
  сворачиванию. Автоматический Quick Lock для такого перехода не подтверждён.
- Для 1.8 нет манифеста версий/внешнего якоря: корректная старая версия того же
  объекта всё ещё принимается. Ограничения conditional version в Core — У-24.
  Проверка поддерева перед move не является транзакцией между несколькими
  клиентами. Внешний криптографический аудит не проведён, формат экспериментальный.
- При Clear без quick-unlock host текущие файлы удаляются, но старый quick wrapper
  и неуничтоженный отдельный ключ могут восстановить старую копию. Теперь это
  ошибка ClearIncomplete. Биометрический quick unlock в UI пока не подключён;
  перед его подключением необходим полный путь уничтожения этого ключа, включая
  auto-wipe. StrongBox сам по себе не служит доказательством rollback resistance.

Основания платформенных выводов:
[DocumentsContract.isChildDocument](https://developer.android.com/reference/android/provider/DocumentsContract#isChildDocument(android.content.ContentResolver,%20android.net.Uri,%20android.net.Uri))
и [KeyMint rollback resistance](https://source.android.com/docs/security/features/keystore/implementer-ref#rollback-resistance).
Схема формата и гарантии остаются в [спецификации](../format/paranoic-v1.md).
