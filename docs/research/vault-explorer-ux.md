# Vault Explorer: как устроено взаимодействие (разбор для Paranoic)

Источник: [gitcortex-Ai/Vault_explorer_MoD](https://github.com/gitcortex-Ai/Vault_explorer_MoD) (`e400abe`), неофициальная модификация [R0b0To/VaultExplorer](https://github.com/R0b0To/VaultExplorer). Flutter/Dart, Kotlin и C++.

**Лицензия GPLv3.** Код, тексты и оформление в Paranoic не переносятся. Берётся только логика взаимодействия: порядок шагов, что и где показывается. Всё реализуется своими словами и своим кодом на Compose.

Разбирались экраны, тексты интерфейса (`lib/l10n/app_en.arb`) и выбор хранилищ на Android. Приложение на устройстве не запускалось.

## 1. Главный экран — список хранилищ

- Главный экран — «Хранилища» (Vaults): карточки запомненных контейнеров и папок-хранилищ.
- На карточке: имя, формат, состояние («Открыт» / «Заблокирован»), свободное место, кнопка блокировки. Из меню — «Изменить» и «Убрать»; убирание с отменой («Убрано "…"» → «Отменить»). Убрать открытый нельзя: сначала заблокировать.
- Отдельная карточка «Локальное хранилище» — обычные файлы телефона.
- Пустой экран объясняет, с чего начать: открыть существующий, подключить USB или создать новый.
- Одна кнопка «Добавить хранилище» открывает лист с вариантами:
  - **Открыть существующий контейнер**;
  - **Открыть USB-накопитель** / **Форматировать USB** (только если подключён);
  - **Создать новый контейнер**.

Главное отличие от Paranoic: ничего не зависит от того, какая папка выделена в файловом менеджере. Хранилище — самостоятельный объект со своей карточкой.

## 2. Создание — мастер по шагам

Индикатор шагов, «Назад» / «Далее», последний шаг — «Создать».

1. **Основное.** «Что создать?» — **файл-контейнер** (VeraCrypt, LUKS…) или **папку-хранилище** (Cryptomator, gocryptfs, CryFS). Формат — чипами. Для контейнера: имя файла, размер (МБ/ГБ), папка назначения. Для папки-хранилища — «Выберите пустую папку» через системный выбор папки. Сразу объясняются ограничения формата: «папки-хранилища не поддерживают ключевые файлы, PIM, скрытые тома и выбор шифров».
2. **Безопасность.** Пароль и повтор, ключевые файлы, PIM; переключатель «Запомнить контейнер» — закрепить на главном экране.
3. **Шифрование и файловая система** — только если у формата есть выбор (шифр, хэш, ФС).
4. **Скрытый том** — только для форматов, где он есть.
5. **Случайность** — пользователь водит пальцем по экрану, это добавляется к энтропии.
6. **Проверка** — сводка всего выбранного перед созданием.

После создания: «Контейнер создан», карточка появляется на главном экране.

## 3. Открытие существующего

- Лист «Открыть контейнер»: сначала **«Файл-контейнер» или «Папка-хранилище»**, затем «Нажмите, чтобы выбрать…» — системный выбор файла или папки.
- **Формат определяется сразу после выбора, до пароля.** Они смотрят, есть ли в выбранной папке файлы конкретного формата. Если нет — понятная ошибка «не похоже на хранилище Cryptomator» вместо «неверный пароль».
- Если запомненный контейнер пропал: «Контейнер не найден — перемещён, удалён или хранилище отключено» и кнопка «Найти файл».
- Пока идёт расшифровка — что именно делается: «Пробую AES (обычный том)…», «Ключ 2 из 8…».
- Способы входа на контейнер: пароль, PIN, графический ключ, биометрия.

## 4. «Окна» — вкладки и две панели

- В файловом менеджере **вкладки**: «Новая вкладка», «Закрыть другие», «Закрыть слева/справа», «Дублировать», «Открыть в новой вкладке». Есть лимит числа вкладок.
- **Две панели рядом** (настройка «Две панели»): на широком экране или в альбомной ориентации две вкладки показываются рядом. Вкладку можно «перенести в другую панель», файлы перетаскиваются между панелями.
- **Виды списка**: таблица с колонками, подробный список, компактный список, **сетка-галерея** (плитки), «кирпичная кладка».

## 5. Настройки

Хаб из разделов, у каждого — строка с кратким содержимым; есть **поиск по настройкам**.

- **Безопасность и приватность:** блокировка приложения (пароль, PIN, графический ключ, биометрия с запасным способом), когда блокировать (сразу, по выключению экрана, по таймауту), автоблокировка открытых хранилищ, **«Запретить скриншоты»** (включаемая настройка), маскировка под другое приложение, экстренная блокировка и «пароль под принуждением».
- **Ключи и доступ к системе:** «Быстрый доступ к хранилищу» (All Files Access для прямых операций с файлами; без него — системный выбор папок, медленнее), работа хранилищ в фоне, USB, отдача файлов через системный выбор файлов, «Поделиться» в хранилище.
- **Хранилища и файлы:** что открывать после разблокировки, ассоциации файлов, удаление исходников после импорта.
- **Файловый менеджер:** вид, панель инструментов, действия над файлами.
- **Внешний вид:** тема, язык.
- **Резервная копия и отладка:** экспорт и импорт настроек, **«Подробный журнал»**, **просмотр журнала** в приложении (поиск, копирование, сохранение, очистка), «Сообщить о проблеме».

**Настройки отдельного хранилища** (лист из карточки): имя; автоблокировка именно этого хранилища (как в приложении / сразу / только по экрану / никогда); «всегда только чтение»; смена пароля; кэш ключа со сроком; синхронизация с папкой; миниатюры; «Сведения» — шифр, формат и технические детали.

## 6. Что из этого брать Paranoic (предложение)

Привязка к [PLAN.md](../../PLAN.md).

**Брать:**

- **Главный экран хранилищ с карточками** и кнопка «Добавить» с листом «Открыть / Создать» → E4.1. Раздел «Шифрование» перестаёт зависеть от выделения в «Файлах».
- **Мастер создания по шагам** (формат → место → пароль → параметры формата → проверка → создать) → пункт 10. VeraCrypt — третьим форматом в том же мастере (пункт 14).
- **Определение формата сразу после выбора папки или файла**, до пароля, и честная ошибка «здесь нет хранилища» → пункт 2 (ложное «неверный пароль»).
- **«Контейнер не найден» с «Найти файл»** вместо общей ошибки.
- **Прогресс расшифровки словами**: KDF у нас долгий, сейчас пользователь видит только крутилку.
- **Вкладки и две панели** в «Файлах» → пункт 11. Две панели особенно полезны для копирования между обычной папкой и открытым хранилищем.
- **Сетка-галерея** как один из видов → пункт 11.
- **Настройки хабом с разделами и поиском**; **настройки отдельного хранилища** (имя, автоблокировка, только чтение, смена пароля, сведения) → пункт 12.
- **Подробный журнал и его просмотр в приложении** → пункт 8 (отладка). У нас — без путей и имён файлов.
- **«Запретить скриншоты» как настройка**, по умолчанию включено → пункт 9, вариант «а».

**Создание на телефоне через SAF.** Они создают папки-хранилища в выбранной **пустой** папке через системный доступ, без атомарного переименования. У нас создание требует атомарного переименования без замены — отсюда отказ на телефоне (E2.8). Предложение: в новой пустой папке, которую мы сами только что создали, заменять нечего, поэтому там можно разрешить более простой порядок записи, не снижая защиту от перезаписи чужих данных. Это изменение ядра — нужно решение владельца.

**Не брать или отложить (противоречит модели безопасности Paranoic или лишнее сейчас):**

- кэш ключа в Android Keystore «для быстрого открытия» и автоблокировку «никогда» — ослабляют защиту;
- работу хранилищ в фоне с ключами в памяти после выхода из приложения;
- автоматизацию через Tasker/MacroDroid — лишняя поверхность атаки;
- маскировку под другое приложение и «пароль под принуждением» — возможно позже, отдельным решением;
- камеру, редакторы фото, видео и аудио, менеджер паролей, аутентификатор — вне задач Paranoic;
- «All Files Access» — широкое разрешение. Paranoic обходится выбранными папками; включать только если владелец решит.
