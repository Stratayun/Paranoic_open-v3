# Android: сценарии на отдельном тестовом устройстве

Не автоматический runner и не отметка готовности. Выполнять после команды
владельца на чистом эмуляторе/отдельном устройстве без личных аккаунтов и данных.
Фиксировать commit, SHA-256 APK, ABI, Android/API, OEM/provider, размер страницы
памяти и точные шаги; результат и блокеры переносить в корневой ROADMAP.md.
Провал ожидаемого свойства — дефект, а не повод заменить проверку заглушкой.

Все файлы, аккаунты и каталоги ниже — одноразовые тестовые. Для каждого конфликта
до/после сравнивать содержимое и hash исходника/существующего назначения.
Отдельные проверки ниже требуют ещё не реализованных возможностей; отсутствие
реализации отмечать как блокер/недоступность, не как пройденную проверку.

| Сценарий | Действия | Ожидаемое свойство / evidence |
| --- | --- | --- |
| ABI и запуск | Чистая установка под arm64-v8a; отдельный x86_64 emulator; затем устройство в 16-КиБ режиме | Нет ошибки JNA/UniFFI/native load; фактический page size, ABI и APK записаны |
| SAF picker и lifecycle | Выбрать дерево; отменить выбор; повторить после поворота/фона; повторно запустить процесс приложения | Отмена не создаёт grant; реальный выбранный grant сохраняется; фон не показывает старый snapshot/ложный успех |
| Отзыв разрешения | На тестовом провайдере отозвать разрешение до чтения и во время операции | Явная ошибка permission/недоступности; данные не заменены; повтор записи только явным действием |
| Непереносимые/дублирующиеся имена | Провайдер с good.txt, bad:name, trailing. и двумя одинаковыми именами | Доступные строки показаны; непереносимые/неоднозначные пропущены и посчитаны; копирование не выбирает случайный дубликат |
| Create-new и конфликт | Новая папка/копия; уже существующее имя; провайдер сам меняет имя; конкурентное создание того же имени | Назначение и исходник не перезаписаны; чужой объект не удалён; собственный временный объект убран либо явно требуется внимание |
| SAF rename с перезаписью | Одноразовый провайдер, заменяющий существующий документ при rename; конкурентный писатель | Проверить реальную гарантию провайдера. Текущий temp+rename не гарантирует no-replace для любого SAF; такой provider не считать безопасным для записи |
| Разрыв записи | Обрыв сети/убийство тестового провайдера после принятия записи, до ответа | Неопределённый результат показан явно; приложение не повторяет запись автоматически; временные объекты учтены |
| Поток облачного провайдера | Открыть PDF/медиа из pipe; последовательное чтение, seek назад, недоступный размер | Поддерживаемое чтение работает; неподдерживаемый seek/размер даёт capability error; нет зависания или ложного успеха |
| PDF и граница процесса | Открыть тестовый PDF, листать/искать, закрыть viewer, оборвать/сломать worker | Main process остаётся жив; worker закрывается/тайм-аут виден; чтение/разбор не повторяется на каждую страницу; ошибки не дают фиктивную страницу |
| PDF sandbox — блокер | Сопоставить PID/UID, manifest/service, native mappings; попробовать из тестового worker открыть app-private canary | Worker должен быть действительно изолирован от UID/памяти/каталогов с ключами; обычный subprocess с тем же UID не проходит. isolatedProcess service ещё требуется |
| Медиа и фон | Длинный файл, seek, pause/resume, закрыть экран и быстро открыть другой файл | Нет воспроизведения старого файла и старых callbacks; handles освобождены; нет plaintext spool; реальные кодеки и ошибки зафиксированы |
| Защищённый store | Перезапуск приложения; невозможность получить ключ; сбой сохранения; optional системный вход | Нет тихого создания нового store поверх недоступного; ошибка сохранения видна; состояние не выдаётся за подтверждённое |
| Google-вход — после реализации | Отдельный тестовый аккаунт и зарегистрированный Android OAuth client с правильным package/SHA-1; отмена/отзыв/ошибка сети | Нет токенов в UI state/логах; отмена не подключает облако; токен получает новый Rust transport через согласованный мост. Наличие Go не отменяет настройки OAuth |

Минимум API 26 и актуальная Android на реальном ARM64; API 29+ дополнительно
покрыт fixture ContentResolver в instrumented tests. Поддержку конкретного OEM,
Google Drive SAF и 16-КиБ режима нельзя выводить из одного успешного эмулятора.

При публикации evidence не включать URI с личными путями, токены, PDF/файлы
пользователя, Keystore material или необработанные дампы памяти.


## Новые сценарии 1.4 / 1.5 / 2.1 — подготовлено, не выполнено (2026-11-13)

Использовать отдельные тестовые заметки, папки и архивы. Ни одна строка ниже не означает успешный прогон.

| Удаление Cryptomator | Создать папку с вложенными файлами, открыть подтверждение удаления; отменить, затем подтвердить | До подтверждения изменений нет; текст явно говорит о всём содержимом; прерванный план появляется в «Требуют внимания» |
